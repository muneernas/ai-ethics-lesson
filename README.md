# AI & Ethics — Interactive Lesson

A polished, interactive classroom presentation for **Grade 9–10** on AI ethics.

**Theme:** Bias · Privacy · Surveillance · AI in Hiring · Debate  
**Length:** ~40 minutes · 24 slides  
**Pattern:** Scenario → Student decision → Reveal → Discussion → Concept

## Present

```bash
npm install
npm run dev
```

Open the local URL, press **F** for fullscreen.

### Controls

| Key | Action |
| --- | --- |
| `→` / `Space` | Next slide |
| `←` | Previous slide |
| `N` | Speaker notes |
| `F` | Fullscreen |
| `?` | Help |

Click voting options, reveal buttons, privacy scale, surveillance hotspots, and the debate timer during class.

## Design

Uses the Ahliyyah & Mutran-inspired palette (black + gold) with a dark, modern technology aesthetic.

## Deploy

Static Vite build — works on Vercel with zero config beyond `vercel.json` SPA rewrite.
